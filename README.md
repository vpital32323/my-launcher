# My Launcher

Красивый и плавный лаунчер Minecraft для собственного Fabric-клиента.
Electron + React + Framer Motion.

## Возможности

- Анимированный фон (дрейфующие градиенты + частицы), стеклянный интерфейс
- Плавные переходы между экранами, анимированный прогресс запуска
- Выбор любой релизной версии Minecraft
- Автоматическая установка Fabric
- Вход по нику (оффлайн) или через аккаунт Microsoft
- Менеджер модов: добавить, включить/выключить, удалить
- Настройки: оперативная память, путь к Java

## Запуск

Нужны Node.js 18+ и Java (17 для 1.18–1.20.4, 21 для 1.20.5+).

```bash
npm install
npm run dev      # режим разработки с горячей перезагрузкой
npm run start    # собрать интерфейс и запустить
npm run dist     # собрать установщик (exe / dmg / AppImage)
```

Игровые файлы лежат в папке `.mylauncher` внутри AppData (Windows),
`~/Library/Application Support` (macOS) или `~/.config` (Linux).

## Как сделать клиент «своим»

- Название и слоган: `src/config.js`
- Цвета и анимации: переменные в начале `src/styles.css`
- Свои моды клиента кладутся в папку `mods` (кнопка «Открыть папку» в разделе «Моды»)
- Иконка приложения: добавь `build/icon.ico` / `build/icon.icns` для electron-builder
